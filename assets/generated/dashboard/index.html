How this was made

Each session is one fresh call to Claude Opus 5.5 or Fable 5.1 with the hackathon email screenshot, sometimes the info-session deck, and one of 40 student-style requests such as "give me ideas for this hackathon". Haiku 5.5 pulled each reply's top five ideas and mapped each onto — finance workflows, structured after APQC's Process Classification Framework for financial resources plus industry and consumer finance. It also flagged ideas that overlap a product Ramp already sells: — of them. The full run cost —. The API runs without the claude.ai app's system prompt, memory and web search, so real students' answers may differ somewhat.
